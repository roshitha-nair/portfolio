AI-Powered Customer Support Analytics

SQL · Python · NLP · DuckDB · Power BI

Processed 8,469 customer support tickets into a full analytics pipeline combining sentiment classification and BERTopic-based topic discovery, surfacing 30 recurring support themes, plus a CSAT-grounded dissatisfaction-risk model reaching 91.4% recall on CSAT-observed tickets — surfacing not just which tickets are at risk, but what's actually driving dissatisfaction.

Re-scoped the model target mid-build after data profiling showed no defensible escalation label existed in the raw data — moved from a proposed escalation-risk target to a CSAT-grounded dissatisfaction target instead of forcing a weak label, then built a Gradient Boosting model on top of it.

Modeled the pipeline into a DuckDB star schema and shipped a 3-page Power BI dashboard (Executive Overview, Issue Analysis, AI Insights), with an optional local FastAPI demo exposing live sentiment, topic, and risk inference.
